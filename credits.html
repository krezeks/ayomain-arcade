Lisensi & Kredit

Semua game di ayomain arcade adalah karya open-source dari para pembuatnya masing-masing. Portal ini hanya merakitnya jadi satu tempat, mengikuti model katalog Attogram Games (MIT). Kode sumber lengkap setiap game ikut disertakan di foldernya, termasuk berkas lisensinya — sesuai syarat lisensi MIT, Apache-2.0, GPL-3.0, dan AGPL-3.0.

Nama-nama game seperti Pac-Man adalah merek dagang pemiliknya masing-masing; versi di sini adalah klon open-source buatan komunitas, bukan rilis resmi.
